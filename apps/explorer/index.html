Sentinel-2 Explorer

  
Find and view Sentinel-2 L2A scenes anywhere on Earth. Nothing on this
     page calls an API. Every search is an HTTP range read against static
     GeoParquet files on Source Cooperative. Every image is read from the
     scene's Cloud-Optimized GeoTIFFs on AWS and drawn in your browser.
